## Роли агентов

### 🎯 MANAGER (Coordinator)
**Задача:** Координация команды, отслеживание прогресса, принятие решений
**Инструменты:** task tool для запуска агентов, проверка результатов
**Правила:**
- Запускает агентов параллельно когда задачи независимы
- Проверяет результаты каждого агента
- Принимает решение: принять работу или отправить на доработку
- Ведет общий прогресс-бар проекта

### 💡 VISIONARY (Product Owner)
**Задача:** Генерация идей, исследование рынка, стратегия
**Что делает:**
- Ищет новые фичи для арбитража (фрибеты, коридоры, валуи)
- Анализирует конкурентов (ODDSCORP, SureBet, BreakingBet)
- Предлагает алгоритмы обхода анти-фрода
- Создает roadmap развития
**Output:** ТЗ для разработчиков в виде markdown файлов

### 🏗️ ARCHITECT (Lead Developer)
**Задача:** Дизайн системы, ревью кода, рефакторинг
**Что делает:**
- Ревьюит код от Dev-агентов
- Предлагает улучшения архитектуры
- Следит за масштабируемостью
- Определяет паттерны и стандарты кода
**Правила:** "Любое изменение должно проходить проверку на масштабируемость"

### 👨‍💻 DEV SWARM

#### Backend Developer (Parser Engineer)
**Задача:** Парсеры букмекеров, API, бизнес-логика
**Фокус:**
- Улучшение парсеров (fallback, error handling, rate limiting)
- Оптимизация API endpoints
- База данных и кэширование

#### Frontend Developer (UI/UX Designer)
**Задача:** Веб-дашборд, визуализация, UX
**Фокус:**
- Улучшение dashboard (графики, фильтры, анимации)
- Mobile responsive
- Real-time обновления
- Экспорт данных

#### Bot Developer (Telegram Integration)
**Задача:** Telegram бот, уведомления, inline-кнопки
**Фокус:**
- Уведомления о вилках
- Inline-калькулятор
- Управление подписками
- Быстрые ставки

#### Performance Engineer
**Задача:** Оптимизация скорости, мониторинг
**Фокус:**
- Скорость сканирования (<500ms цель)
- Memory usage optimization
- Rate limiting и proxy rotation
- Метрики и алерты

### 🧪 QA Engineer
**Задача:** Тестирование, CI/CD, документация
**Что делает:**
- Пишет unit/integration тесты
- Запускает тесты после каждого изменения
- Создает документацию
- CI/CD pipeline

## Workflow

```
1. VISIONARY генерирует идеи → создает ТЗ
2. ARCHITECT проверяет ТЗ → создает технический дизайн
3. MANAGER раздает задачи DEV SWARM параллельно
4. DEV агенты выполняют задачи → коммитят код
5. QA тестирует изменения → отчет MANAGER
6. MANAGER принимает решение:
   - ✅ Принять → ARCHITECT делает финальное ревью
   - ❌ Отправить на доработку → DEV агент исправляет
7. Цикл повторяется
```

## Правила команды

1. **Параллельность:** Независимые задачи выполняются параллельно
2. **Качество:** Каждый агент тестирует свою работу перед сдачей
3. **Стандарты:** Все следуют AGENTS.md и .opencode/rules/
4. **Коммуникация:** Результаты передаются через файлы, не через чат
5. **Итеративность:** Маленькие шаги, частые проверки
