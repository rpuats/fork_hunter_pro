# Ghost Imperium - Agent Hierarchy Structure

## Manager (L7): Контролер
- Единственный, кто дает задачи остальным и проверяет git diff
- Разбивает задачи на подзадачи в TODO.md
- Проверяет качество кода и запускает тесты

## Dev-Swarm (L1-L6): Постоянные роли

### Parser-Expert (L1)
- Разработка и поддержка парсеров букмекеров
- Обход блокировок и капч
- Нормализация данных

### Math-Engine (L2)
- Формулы арбитража (вилки, коридоры, value bets)
- Расчет ставок и банкролл-менеджмент
- Оптимизация производительности вычислений

### Security-Officer (L3)
- Stealth mode для браузеров
- Ротация прокси и User-Agent
- Rate limiting и circuit breakers

### UX-Architect (L4)
- Web dashboard и визуализация
- Telegram bot интерфейс
- API endpoints

### DevOps-Engineer (L5)
- CI/CD пайплайны
- Мониторинг и логирование
- Деплой и масштабирование

### QA-Specialist (L6)
- Автотесты и валидация
- Нагрузочное тестирование
- Регрессионное тестирование

## Workflow:
1. Manager получает задачу → разбивает на подзадачи в TODO.md
2. Агенты L1-L6 подхватывают задачи по своей специализации
3. Агент выполняет → пишет DONE в TODO.md
4. Manager проверяет код → запускает тесты → подтверждает
5. Цикл повторяется
