# 🔧 Исправления — 10 апреля 2026

## ✅ Исправлено: Баг калькулятора вилок (КРИТИЧНО)

### Проблема
Калькулятор **НЕ** находил вилки между разными БК для одного матча из-за неправильной группировки рынков.

**Корневая причина:**
```rust
// БЫЛО (НЕПРАВИЛЬНО):
let key = if let Some(line) = odd.line {
    format!("{}|{}|{}", odd.market, odd.odds_type, line)  // ❌ Over/Under в разных группах!
} else {
    format!("{}|{}", odd.market, odd.odds_type)
};
```

Для тоталов Over 2.5 и Under 2.5 создавались **разные ключи**:
- `"Total|Over|2.5"` 
- `"Total|Under|2.5"`

Поэтому они никогда не попадали в одну группу для сравнения → вилки не находились!

### Решение
```rust
// СТАЛО (ПРАВИЛЬНО):
let key = if let Some(line) = odd.line {
    format!("{}|{:.2}", odd.market.to_lowercase(), line)  // ✅ Over/Under в ОДНОЙ группе
} else {
    format!("{}|none", odd.market.to_lowercase())
};
```

Теперь Over 2.5 и Under 2.5 оба в группе `"total|2.50"` → сравниваются между БК → находятся вилки!

### Результат
- ✅ **8/8 тестов калькулятора** проходят (было 5 fail)
- ✅ Калькулятор теперь правильно ищет вилки跨-БК
- ✅ Скanner уже имеет `find_cross_bk_surebets()` для матчинга по fingerprint
- ✅ **82/82 всех тестов проекта** проходят

## ✅ Улучшено: Нормализация событий для跨-БК матчинга

### Проблема
Fingerprint событий не учитывал **лигу**, только команды. Это приводило к ложным совпадениям (например, "Реал vs Барселона" из Ла Лиги и товарищеского матча).

### Решение
1. **Добавлена нормализация лиг** в `event_fingerprint()`:
   - "АПЛ" = "Английская Премьер-Лига" = "EPL" = "england" → `"epl"`
   - "Ла Лига" = "Primera Division" = "Испания" → `"laliga"`
   - "РПЛ" = "Russian Premier League" = "Россия" → `"rpl"`

2. **Fingerprint теперь включает лигу**:
   ```rust
   // БЫЛО:
   format!("{:?}|{}|{}", event.sport, home, away)
   
   // СТАЛО:
   format!("{:?}|{}|{}|{}", event.sport, league, home, away)
   ```

3. **Улучшена нормализация команд**:
   - Удаление префиксов: "ФК", "СК", "ПК", "ХК"
   - Удаление городов: "Москва", "СПб", "Петербург"
   - Удаление пунктуации: `()`, `.`, `,`, `'`, `_`
   - Sort home/away для консистентности

### Результат
- ✅ Матчинг событий между БК стал **точнее**
- ✅ Меньше ложных совпадений
- ✅ Больше реальных вилок находится

### Файлы изменены
1. `crates/engine/src/calculator.rs` — метод `group_by_market()` (исправлен баг с группировкой)
2. `crates/scanner/src/engine.rs` — методы `event_fingerprint()`, `normalize_league_name()` (улучшен матчинг)
